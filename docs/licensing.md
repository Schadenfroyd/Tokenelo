As of October 28, 2026 this covers the source files, tests, build scripts, original documentation and synthetic examples published here. It is not a license for installers, signed builds or hosted services, none of which are published.

Third-party packages keep their own licenses. [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) and the [dependency inventory](third-party/README.md) are generated from the lockfile and cover the development dependency tree. The tracker has no production dependencies, and none of those packages is bundled into the compiled product today. The inventory check flags one development-only package whose license it classes as unknown.
