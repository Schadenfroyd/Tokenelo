# Release and licensing status

The public repository currently contains project documentation and repository tooling. The tracker source, installers, and an open-source license grant have not yet been published.

Apache-2.0 is the approved licensing plan for the cleared tracker contribution, including original documentation and synthetic examples, with third-party notices preserved. The final license must identify the actual licensor and match the reviewed release scope. Source publication and the license grant remain pending clearance; this document is not a license grant.

The approved Apache 2.0 plan would permit companies, vendors, and developers to use and extend the cleared tracker source, including commercial reuse and forks. Product names and endorsement rights are handled separately.

An actual license will be present at the repository root when the source release is issued. Until then, do not treat the absence of a license as open-source permission. [GitHub's explanation of licensing](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
