# Frequently asked questions

## Can I install Tokenelo today?

No public installer is available. The application source is published under Apache 2.0 and can be built from a checkout by following the [quick start](quick-start.md), which is a release draft with clean-install acceptance still pending. The product is in internal alpha. Follow the [status page](status.md) and [roadmap](roadmap.md).

## Is it open source?

Yes, the application source is released under Apache 2.0; see the [license](../LICENSE) and the [licensing details](licensing.md). Installers and signed builds are not published.

## Is the tracker intended to be free?

Yes. Free local tracking, reporting, and useful data depth are the primary product commitment. The tracker is designed to require no paid subscription, Tokenelo account, or central upload. Optional future hosted services would need separate terms; none is announced here.

## Does a cost total equal my vendor invoice?

No. Standard API-equivalent comparisons use configured prices and recorded usage. Invoices, served tiers, negotiated discounts, quotas, rounding, and uncaptured activity can differ. [How to interpret the data](data-accuracy.md)

## Which platforms and tools are supported?

Windows, macOS, and Linux are under internal verification. Internal adapters include Claude Code, Codex, and configured local inference. Public support depends on the tested platform and source-format matrix in the [support matrix](support-matrix.md), a release draft; no complete public compatibility claim is made yet.

## Are my prompts uploaded or stored?

Prompt/response bodies are not part of the normalized local event contract. Configured metering proxies can process request/response traffic in memory to obtain counters. Metadata, session titles, identifiers, and paths can still be sensitive. Optional fleet configuration and any future upload policy must be explicit. [Read the privacy model](privacy.md)

## How can I help now?

Suggest improvements, report confusing documentation or a tracking problem using fabricated records, or send a source or documentation pull request ([contributing](../CONTRIBUTING.md)). Do not post raw logs, databases, tokens, or private project paths. Use [issue forms](https://github.com/Schadenfroyd/Tokenelo/issues/new/choose); report vulnerabilities through [private reporting](https://github.com/Schadenfroyd/Tokenelo/security/advisories/new).
