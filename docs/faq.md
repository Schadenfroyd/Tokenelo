# Frequently asked questions

## Can I install Tokenelo today?

No public installer or supported source build is available yet. The product is in internal alpha. This repository publishes project documentation and release preparation. Follow the [status page](status.md) and [roadmap](roadmap.md).

## Is it open source?

Apache 2.0 is the approved plan for the cleared tracker release. The exact source and license grant remain pending counsel clearance; this repository does not yet grant an open-source license. [Licensing details](licensing.md)

## Is the tracker intended to be free?

Yes. Free local tracking, reporting, and useful data depth are the primary product commitment. The planned tracker requires no paid subscription, Tokenelo account, or central upload. Optional future hosted services would need separate terms; none is announced here.

## Does a cost total equal my vendor invoice?

No. Standard API-equivalent comparisons use configured prices and recorded usage. Invoices, served tiers, negotiated discounts, quotas, rounding, and uncaptured activity can differ. [How to interpret the data](data-accuracy.md)

## Which platforms and tools are supported?

Windows, macOS, and Linux are under internal verification. Internal adapters include Claude Code, Codex, and configured local inference. Public support depends on the cleared release's tested platform and source-format matrix; no complete public compatibility claim is made yet.

## Are my prompts uploaded or stored?

Prompt/response bodies are not part of the normalized local event contract. Configured metering proxies can process request/response traffic in memory to obtain counters. Metadata, session titles, identifiers, and paths can still be sensitive. Optional fleet configuration and any future upload policy must be explicit. [Read the privacy model](privacy.md)

## How can I help now?

Suggest improvements, report confusing documentation, or describe a tracking problem using fabricated records. Do not post raw logs, databases, tokens, or private project paths. Use [issue forms](https://github.com/Schadenfroyd/Tokenelo/issues/new/choose); report vulnerabilities through [private reporting](https://github.com/Schadenfroyd/Tokenelo/security/advisories/new).
