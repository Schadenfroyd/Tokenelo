The accountability workflow

Review the same scope on both sides before deciding what a difference means.

  2. 02

    Review the records

  3. 03

    Compare carefully

    Use the same window and call out price assumptions, gaps, and differences.

  4. 04

    Document the question

    Bring the reviewed report and unresolved points to your vendor.

The report is intended to support a better conversation. Automatic invoice reconciliation is not a released capability.

Trust and data boundaries

Local evidence needs careful handling.

The public docs describe intended behavior and current qualifications. The tracker source is available for public inspection under Apache 2.0.

T

Local use is the plan.

The tracker is designed to provide useful local tracking and reporting without a Tokenelo account, paid subscription, or central upload requirement.

What the docs describe

Normalized local records hold counts and metadata. The local metering proxy, which starts by default and listens on loopback only, can process request and response traffic in memory to obtain counters.

What deserves review

Session titles, identifiers, host labels, project paths, and exports can reveal sensitive activity. Review files before sharing them.

Questions people ask first

Before you follow along.

Can I install Tokenelo today?

No. There is no public installer. The source is public and can be built from a checkout, but that path is a release draft and platform support is not claimed. The project is in internal alpha. Follow the release status for current progress.

Is the Tokenelo application open source now?

Yes, the application source is published under Apache 2.0. Installers and signed builds are not published, and the project is in internal alpha. Read the licensing status.

Does an API-equivalent cost equal my invoice?

No. A comparison uses recorded usage and a configured price table. Subscription quotas, served tiers, negotiated rates, discounts, rounding, and uncaptured activity can differ from a vendor bill. Learn how to read the numbers.

Which tools and platforms will work?

Internal adapters include Claude Code, Codex, and configured local inference. Supported formats and coverage vary. Windows, macOS, and Linux are under internal verification; the support matrix is a release draft.

What data should I be careful with?

Metadata and exports can contain session titles, identifiers, host labels, and local project paths. Review reports before sharing and use fabricated examples in public issues. See the privacy model.
