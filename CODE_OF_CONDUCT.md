# Community conduct

Help people understand the tool and improve its evidence. Be respectful, specific and constructive. Discuss ideas and behavior; avoid harassment, discrimination, threats, personal attacks and disclosure of private information.

Use public issues for product discussion and sanitized reproductions. Report security issues through the private vulnerability channel. For a conduct concern, request a private channel from the repository owner without publishing personal information.

The repository owner may edit or remove harmful content, close threads or restrict participation. Decisions should consider context and apply the same standards to maintainers and contributors. No private reporting address is invented here; a dedicated channel can be added when staffed.
